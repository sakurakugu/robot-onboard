| 项目       | 蓝口              | 白口                 |
| ---------- | ----------------- | -------------------- |
| USB 控制器 | ohci-platform     | ehci-platform        |
| 速率       | 12 Mbps           | 480 Mbps             |
| 是否经 Hub | ❌ 否              | ✅ 是                 |
| 稳定性     | ⭐⭐⭐⭐              | ⭐⭐⭐                  |
| 带宽       | 低                | 高（但共享）         |
| 适合用途   | 音频 / 串口 / HID | 存储 / 网卡 / 摄像头 |

推荐 蓝口插入麦克风，白口插入音箱（没听到声音大概率是麦克风没插紧）
